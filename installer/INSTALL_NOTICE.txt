DUCKTIMIZER — INSTALAÇÃO LOCAL

Software gratuito e de código aberto, sob licença MIT. Não exige conta,
licença de ativação, compra ou vínculo com este computador.

O aplicativo exige privilégios de administrador para alterar o Windows.
Revise cada grupo antes de aplicar. O modo Debloat remove aplicativos;
a reinstalação deles não é garantida pelo backup das configurações.

Logs e backups ficam armazenados localmente. O aplicativo não envia
telemetria e não consulta serviços de ativação ou atualização.
Atualizações são instaladas manualmente pelo usuário.
